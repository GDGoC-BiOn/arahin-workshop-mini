sudah tersedia.

## Acceptance criteria

- Login berhasil jika email `workshop@example.com` dan password `belajar123`.
- Tampilkan feedback yang jelas saat login berhasil.
- Tampilkan feedback error saat email atau password salah.
- Jangan menambahkan backend atau menyimpan password sungguhan; ini simulasi
  lokal untuk latihan.
- `flutter analyze` dan `flutter test` tetap lulus.

## Cara mulai
