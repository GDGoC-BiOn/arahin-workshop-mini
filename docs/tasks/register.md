# Tugas: Implementasi Registrasi

Branch: `task/register`

Lengkapi method `_register()` di `lib/main.dart`. Form nama, email, dan password
sudah tersedia.

## Acceptance criteria

- Gunakan nama, email, dan password yang dimasukkan pada form.
- Berikan feedback sukses setelah registrasi demo berhasil.
- Berikan feedback yang mudah dipahami bila data tidak memenuhi aturan.
- Simulasi harus tetap lokal; tidak perlu backend atau akun sungguhan.
- `flutter analyze` dan `flutter test` tetap lulus.

## Cara mulai

```sh
git switch task/register
flutter pub get
flutter run
```
